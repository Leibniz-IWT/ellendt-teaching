# Essential Matlab Programming for Process Engineers

Welcome to the course materials for **Essential Matlab Programming for Process Engineers**. 

This folder contains MATLAB scripts (`.m`) and data files that accompany the lectures. These files are designed to help you build a strong foundation in MATLAB programming and apply it to solve common process engineering problems.

## 🚀 How to Run the Scripts

To interact with these files, you will need access to MATLAB. 

**Running Locally (Recommended)**
1. Clone or download this repository to your computer.
2. Open the **MATLAB** application (or log into MATLAB Online).
3. In the MATLAB interface, use the directory browser on the left to navigate to this downloaded folder, making it your "Current Folder".
4. Double-click any `.m` file to open it in the Editor.
5. Click the **Run** button (the green play icon) in the top menu bar to execute the code.
