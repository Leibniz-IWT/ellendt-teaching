# Atomization Processes

Welcome to the course materials for **Atomization Processes**.

This folder contains interactive Jupyter Notebooks (`.ipynb`) used to simulate and visualize droplet formation and atomization physics.

## 📂 Course Contents
* `droplet_simulation.ipynb`

## 🚀 How to Run
To interact with these simulations, you will need a Python environment with Jupyter Notebook installed. 
1. Clone or download this repository.
2. Open your terminal, navigate to this folder, and run `jupyter notebook`.
